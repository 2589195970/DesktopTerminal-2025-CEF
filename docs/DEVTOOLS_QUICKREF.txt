问题：F12打开DevTools后显示白屏

最快解决方案：
┌──────────────────────────────────────────────────────────────────────────┐
│ 1. 打开系统浏览器（Chrome/Edge/Safari）                                 │
│ 2. 访问: http://localhost:9222                                          │
│ 3. 点击页面中的调试目标                                                 │
│ 4. 完整DevTools在浏览器中打开                                           │
└──────────────────────────────────────────────────────────────────────────┘

备用方案：
  F12打开窗口后，等待10-15秒，内容会逐渐显示

诊断工具：
  Windows:      scripts\test-devtools.bat
  Linux/macOS:  ./scripts/test-devtools.sh

为什么会白屏？
  - CEF 75单进程模式限制
  - DevTools需要时间初始化和渲染
  - 软件渲染（32位/Win7）比GPU渲染慢
